# ClearHunt — удалённые настройки

Этот репозиторий хранит файл **config.json** для расширения **ClearHunt** (ранее FilterJobHH) — фильтра вакансий на hh.ru и зеркалах.

Расширение само скачивает этот файл. Вручную ничего устанавливать не нужно.

## Зачем

Если hh.ru изменит вёрстку сайта — правьте `config.json` здесь.  
Расширение подхватит изменения в течение ~24 часов, без новой версии в магазине расширений (Chrome / Firefox / Opera и др.).

## Важно

- Репозиторий должен оставаться **Public** — иначе расширение не сможет скачать файл.
- В файле нет паролей и личных данных — только технические настройки (селекторы, пороги, маркеры).

## Файлы

| Файл | Назначение |
|------|------------|
| `config.json` | Селекторы страницы hh.ru, пороги фильтров, списки маркеров агентств |
